# Report

What we submit on Canvas, besides the repository link. Owner: the Report and Presentation Lead;
every member writes sections.

| Folder | Submission | Length |
|---|---|---|
| [proposal/](proposal/README.md) | The proposal: problem, algorithms, data, evaluation plan, roles | 2–3 pages |
| [final/](final/README.md) | The final report, and the slides if any | 8–12 pages |

The drafts are written together outside the repository (plan Q8: Google Docs, Overleaf or Word).
Each folder links its draft and keeps the **submitted PDF**.

Where the content comes from:

- **Methodology:** [analysis/](../analysis/README.md), the problem statement, pseudocode and proofs.
- **Results:** [findings.md](../docs/llm-wiki/findings.md) and the plots in `results/`. A number or
  plot that isn't there doesn't go in the report.
- **Contributions:** [CHANGELOG.md](../CHANGELOG.md), where every line names its author, and the
  pull requests' *Contribution* sections.
- **References:** [docs/references.md](../docs/references.md).
