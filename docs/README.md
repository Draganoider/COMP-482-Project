# Docs

Everything written down about the project that isn't code. Start with [plan.md](plan.md). These
pages are written for teammates and for AI assistants working in this repo.

| Where | What's in it | Update it when |
|---|---|---|
| [plan.md](plan.md) | Status, deadlines, team and roles, the decision log, open questions | a phase starts or ends, a decision is made, a question is answered |
| [assignments/project-outline.md](assignments/project-outline.md) | What the course asks for and how it's graded, summarised | the instructor changes or clarifies the requirements |
| [llm-wiki/](llm-wiki/README.md) | What we know and what we measured: [findings](llm-wiki/findings.md), [benchmarking method](llm-wiki/benchmarking.md), [course conventions](llm-wiki/course-conventions.md), [environment](llm-wiki/environment.md) | the day you measure or learn something |
| [proposal/](proposal/README.md) | The proposal checklist and draft, and the [topic comparison](proposal/topic-comparison.md) | working on the proposal |
| [report/](report/README.md) | The final report's structure, who owns each section, and where its evidence lives | working on the report |
| [references.md](references.md) | Every external source: textbook, datasets, articles, code | you use anything we didn't write |

How we keep them useful:

- Update the docs in the same pull request as the change that makes them untrue.
- The llm-wiki describes what is true **now** and what was **measured**. Plans go in `plan.md`.
- Keep pages short, and link to the code instead of copying it.

Working rules for contributors, including AI assistants, are in [../AGENTS.md](../AGENTS.md). The
short version is [../CONTRIBUTING.md](../CONTRIBUTING.md), and every reviewer follows
[../REVIEWING.md](../REVIEWING.md).
