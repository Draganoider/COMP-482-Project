## AI usage

We use AI coding assistants while working on this project, and say so here rather than in each
commit. How we use them:

- **Tools:** *to be filled in by each member* (for example Claude Code, GitHub Copilot, ChatGPT).
- **What for:** drafting and refactoring code, writing tests, setting up the repository and its
  documentation, and reviewing pull requests.
- **What stays ours:** choosing the problem and the algorithms, the correctness proofs and runtime
  analysis, the experiments and every number in the report. Every measured result comes from
  running the code in this repository; none is generated by a model.
- **Review:** every change, whoever or whatever drafted it, is read and approved by a team member
  before it reaches `main`.
